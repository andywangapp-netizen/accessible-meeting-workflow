# What this repo is not

This is a small public intern harness. It does **not** include:

- Real customer or employer accounts
- Passwords, cookies, JWTs, or API tokens
- Hidden answer keys inside case files
- Copied files from a private company repository
- Default service URLs (put your own in local `.env` if you ever need one)

What we kept is only the **idea**: generate a visible input, run a skill, score the output.

Never commit `.env` or `runs/`.
