# Ethics

This project evaluates **communication support** after a meeting. It does not detect, diagnose, treat, or score any disability.

## Data

- Use **synthetic** transcripts shipped in this repo, or new ones you invent.
- Do not add real Zoom recordings, real student/patient meetings, or real disability status attached to a person.
- Do not commit cookies, JWTs, passwords, or `.env` values.

## Language

The skill and evaluator must fail closed on diagnostic or shaming language. See `forbidden.md`.

## Audience

Autism-friendly structure is the first pack. The eval must not assume the user is a child. Adults, teachers, parents, and coaches are in scope as fictional roles only.
